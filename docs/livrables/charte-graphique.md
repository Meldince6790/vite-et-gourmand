# Charte graphique - Vite & Gourmand

## 1. Présentation de l'identité visuelle

L'identité visuelle de **Vite & Gourmand** a été pensée afin de refléter les valeurs d'une entreprise de traiteur :

- qualité des prestations ;
- professionnalisme ;
- simplicité ;
- accessibilité ;
- convivialité.

L'objectif est de proposer une interface claire permettant aux utilisateurs de naviguer facilement entre les différentes fonctionnalités de l'application.

Le choix graphique privilégie une approche sobre et élégante afin de mettre en valeur les menus et les prestations proposées.

---

## 2. Principes graphiques

L'interface repose sur plusieurs principes :

### Simplicité

L'organisation visuelle privilégie une présentation claire des informations afin de faciliter la compréhension des différents contenus.

### Lisibilité

Les éléments graphiques sont conçus pour assurer une lecture confortable :

- contrastes suffisants ;
- hiérarchisation des informations ;
- espaces entre les composants.

### Cohérence

Les composants de l'application utilisent des styles communs afin de conserver une identité homogène :

- boutons ;
- cartes de menus ;
- formulaires ;
- éléments de navigation.

### Professionnalisme

Le design cherche à correspondre à l'image d'une entreprise de traiteur en privilégiant une présentation moderne et épurée.

---

## 3. Palette de couleurs

La palette graphique de **Vite & Gourmand** repose sur des couleurs sobres et chaleureuses afin de conserver une interface professionnelle, lisible et cohérente avec l'univers du traiteur.

Les couleurs utilisées ont pour objectifs :

- mettre en avant les informations importantes ;
- assurer une bonne lisibilité des contenus ;
- renforcer l'identité visuelle de l'application ;
- créer une ambiance associée à la qualité et à la convivialité.

La palette est organisée autour de plusieurs catégories :

### Couleur principale

La couleur principale utilisée est un vert profond (`#2E7D32`), avec une variante plus sombre (`#1B5E20`) pour les états de survol et les liens secondaires.

Elle est principalement utilisée pour les éléments structurants de l'interface :

- barre de navigation ;
- boutons principaux ;
- éléments d'action importants.

Cette couleur apporte une identité visuelle sobre et professionnelle tout en rappelant les notions de naturel et de qualité.

### Couleur secondaire

La couleur secondaire est un beige clair (`#F5F0E6`).

Elle permet d'apporter une touche chaleureuse à l'interface et est utilisée pour :

- certaines zones visuelles secondaires ;
- les éléments de présentation ;
- les espaces nécessitant une différenciation légère avec le fond général.

### Couleur d'accentuation

Une couleur dorée (`#c9a227`) est utilisée comme couleur d'accent sur les fonds clairs.

Sur le fond primaire (en-tête / navigation), l'accent lisible est un crème clair (`#FFF8E1`) afin de conserver un contraste suffisant.

### Couleurs neutres

Les couleurs neutres garantissent une bonne lisibilité des informations.

Elles comprennent :

- un gris foncé (`#333333`) utilisé pour les textes ;
- un beige de page (`#F5F0E6`) utilisé comme couleur de fond générale ;
- un blanc (`#FFFFFF`) pour les surfaces (cartes, pied de page).

Le choix final privilégie une approche minimaliste afin de conserver une interface claire et de laisser les informations principales, notamment les menus proposés, rester au centre de l'expérience utilisateur.

---

## 4. Typographie

L'application **Vite & Gourmand** utilise la police **Arial**, une police sans-serif largement disponible permettant d'assurer une bonne lisibilité sur les différents environnements d'utilisation.

Le choix de cette typographie répond à plusieurs objectifs :

- garantir une lecture confortable des informations ;
- conserver une interface simple et professionnelle ;
- assurer une bonne compatibilité avec les navigateurs.

La hiérarchisation des contenus repose principalement sur :

- la taille des éléments textuels ;
- l'organisation des titres et des sections ;
- la mise en avant des informations importantes.

L'utilisation d'une police standard permet de privilégier la stabilité d'affichage et la simplicité de maintenance du projet.

---

## 5. Composants graphiques

### 5.1 Barre de navigation

La barre de navigation constitue l'élément principal permettant aux utilisateurs d'accéder aux différentes sections de l'application.

Elle repose sur une organisation horizontale des liens afin de faciliter l'accès aux fonctionnalités principales.

Les choix graphiques appliqués sont :

- liens affichés en blanc afin d'assurer un contraste avec la couleur principale de l'interface ;
- utilisation d'une graisse de texte renforcée (`font-weight: bold`) pour améliorer la visibilité ;
- mise en avant de l'élément actif grâce à l'accent crème (`#FFF8E1`) sur fond primaire ;
- ajout d'un effet de survol permettant d'améliorer le retour visuel lors de l'interaction.

### 5.2 Menu utilisateur

Le menu utilisateur permet d'accéder aux fonctionnalités liées au compte connecté.

Il est présenté sous la forme d'un menu déroulant comprenant :

- une ouverture au survol ;
- une zone dédiée aux actions utilisateur ;
- des éléments interactifs avec effets visuels.

Le menu utilise :

- un fond clair ;
- des coins arrondis ;
- une ombre portée permettant de le différencier du reste de l'interface ;
- une mise en évidence des actions lors du survol.

Ces choix permettent de conserver une navigation simple tout en maintenant une cohérence visuelle avec l'identité graphique générale de l'application.

### 5.3 Boutons et éléments d'action

Les boutons de l'application suivent une présentation uniforme afin de conserver une cohérence entre les différentes pages.

Les règles appliquées sont :

- utilisation de la couleur principale (`#2E7D32`) comme couleur d'action principale ;
- texte blanc afin de garantir un contraste suffisant ;
- angles légèrement arrondis afin d'apporter une apparence plus moderne ;
- changement de couleur vers l'accent crème (`#FFF8E1`) lors du survol sur fond primaire.

Ces éléments permettent d'identifier rapidement les actions disponibles pour l'utilisateur.

---

### 5.4 Cartes de présentation

Les informations importantes, notamment les menus proposés, sont présentées sous forme de cartes.

Les cartes utilisent :

- un fond blanc permettant de se distinguer du fond général ;
- des espaces internes afin d'améliorer la lisibilité ;
- des coins arrondis pour conserver une apparence douce et conviviale.

Ce système de cartes permet de présenter plusieurs éléments de manière claire et structurée.

---

### 5.5 Présentation des menus

Les menus sont affichés sous forme d'une grille composée de plusieurs cartes.

Cette organisation permet :

- de comparer facilement plusieurs prestations ;
- de présenter les informations essentielles de chaque menu ;
- de conserver une structure visuelle régulière.

Dans la version actuelle de l'application, l'affichage a principalement été pensé pour un usage sur écran bureautique. Une adaptation complète aux différents formats d'écran pourra être intégrée dans une évolution future.

---

### 5.6 Formulaires

Les formulaires suivent une organisation verticale afin de faciliter la saisie des informations.

Les choix graphiques appliqués sont :

- largeur limitée afin de conserver une zone de saisie confortable ;
- espacement régulier entre les champs ;
- labels mis en évidence grâce à une graisse de texte renforcée ;
- champs avec bordures discrètes et coins arrondis.

Cette organisation vise à rendre les interactions plus simples et plus lisibles pour les utilisateurs.

---

### 5.7 Éléments statistiques

Les zones dédiées aux statistiques utilisent une organisation en colonnes afin de faciliter la comparaison des différents indicateurs.

Les graphiques sont disposés dans des conteneurs permettant :

- une séparation claire des informations ;
- une lecture plus confortable des données ;
- une meilleure organisation de l'espace disponible.

### 5.8 Structure générale de l'interface

L'organisation générale de l'application repose sur une structure composée de trois zones principales :

- un en-tête ;
- une zone de contenu principale ;
- un pied de page.

### En-tête

L'en-tête utilise la couleur principale de l'identité graphique (`#2E7D32`) afin de créer une zone de navigation facilement identifiable.

Les choix appliqués sont :

- fond coloré ;
- texte clair pour assurer un contraste suffisant ;
- espacement interne permettant une meilleure lisibilité.

### Zone de contenu

La zone principale contient les différents contenus de l'application.

Elle repose sur :

- une largeur maximale de `1200px` afin de conserver une lecture confortable ;
- un centrage automatique de la zone ;
- des marges internes permettant d'aérer les informations affichées.

### Pied de page

Le pied de page utilise une surface blanche (`#FFFFFF`) afin de créer une séparation visuelle avec le fond beige de page.

Il permet d'accueillir les informations complémentaires de l'entreprise, notamment :

- les informations légales ;
- les conditions générales de vente ;
- les horaires ;
- les moyens de contact.

Cette organisation permet de conserver une structure claire et cohérente sur l'ensemble des pages de l'application.

---

## 6. Règles d'utilisation

Afin de conserver une cohérence visuelle sur l'ensemble de l'application, plusieurs règles graphiques ont été appliquées.

### Utilisation des couleurs

Les couleurs de la palette doivent être utilisées selon leur rôle défini :

- la couleur principale est réservée aux éléments structurants et aux actions importantes ;
- la couleur secondaire est utilisée pour les zones de séparation ou d'accompagnement visuel ;
- la couleur d'accentuation sert à attirer l'attention sur certains éléments interactifs ;
- les couleurs neutres garantissent la lisibilité des contenus.

Cette organisation permet de conserver une identité visuelle homogène sur toutes les pages.

### Cohérence des composants

Les composants récurrents de l'application doivent conserver une apparence similaire :

- les boutons utilisent la même présentation visuelle ;
- les cartes de contenu suivent une structure commune ;
- les formulaires conservent une organisation identique ;
- les éléments de navigation utilisent les mêmes règles d'affichage.

### Hiérarchisation des informations

L'affichage des informations repose sur une organisation claire :

- les titres permettent d'identifier rapidement les différentes sections ;
- les contenus principaux sont mis en avant ;
- les informations secondaires sont présentées de manière plus discrète.

### Simplicité visuelle

L'application privilégie une approche épurée afin de faciliter la compréhension des fonctionnalités.

Les éléments graphiques sont volontairement limités afin de conserver une interface claire, mettant l'accent sur les informations essentielles et les fonctionnalités proposées.

---

## 7. Adaptation responsive

L'application a été développée principalement pour un affichage sur écran bureautique.

Les choix d'organisation des composants ont été réalisés afin de proposer une interface claire et fonctionnelle sur ce format d'utilisation.

Dans la version actuelle de l'application, l'adaptation complète aux différents formats d'écran n'a pas encore été finalisée.

Les principaux éléments concernés par cette évolution sont notamment :

- l'organisation des cartes de menus ;
- la navigation ;
- la disposition des contenus ;
- l'adaptation des formulaires.

Cette évolution permettra d'améliorer l'expérience utilisateur sur les supports mobiles et d'assurer une utilisation plus confortable sur un plus grand nombre de formats d'affichage.
